H. HOW TO PUT THESE THROUGH A PREFIX
----------------------------------------------------------------------
Option 1 (no code edits, recommended): serve the build from a small local reverse proxy
  that forwards /api/*, /assets/* and /ws/* to https://1v1lolreloaded.com (wss for /ws).
  Everything above then works as if the build were on that origin. Keep the page on
  localhost and set the WS path so the 19090 branch is skipped (needs the Option 2 WS patch,
  or run the proxy's websocket on :19090).

Option 2 (patch the code): define window.__API_ORIGIN = 'https://1v1lolreloaded.com' in
  index.html before the mocks load, then:
    - server-mock.js (63) and firebase-config.js (5): replace location.origin with
      (window.__API_ORIGIN || location.origin). The startsWith(location.origin) "already
      rewritten" checks must use the same value.
    - login.js: prefix /api/auth/google (x2) and /api/auth/logout.
    - server-mock.js WebSocket wrapper: when __API_ORIGIN is set, skip the localhost ->
      :19090 branch and use the __API_ORIGIN host instead of location.host.
  Caveat: cross-origin calls need the live server to send CORS headers for your origin,
  and /api/auth/* may rely on cookies, which browsers can block cross-site. If that
  happens, use Option 1.
