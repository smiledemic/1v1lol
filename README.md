# 1v1lol

## 1v1lol: Reloaded

A working HTML5 revival of **1v1.LOL**, based on **v446.UNITY**.

## Game Modes

### Solo

* **Battle Royale**
* **1v1 Clash for Trophy**

### Practice

* **Free Build**
* **Battle Royale Practice**
* **Zombies**
* **Aim Trainer**

### Custom

Custom modes are available **only while in Party Mode**:

* **Zone**
* **City Zone**
* **1v1 Clash**
* **Battle Royale**
* **Big Box**
* **Deathmatch**
* **Zombies**
* **1v1 Arena**

## Controls

### Movement

| Key             | Action   |
| --------------- | -------- |
| `W` `A` `S` `D` | Movement |
| `Space`         | Jump     |
| `Left Shift`    | Crouch   |

### Interaction & Weapons

| Key / Input       | Action        |
| ----------------- | ------------- |
| `E`               | Pick up       |
| `F`               | Pickaxe       |
| `1` - `5`         | Weapon slots  |
| `Left Click`      | Shoot         |
| `Hold Left Click` | Zoom          |
| `B`               | Spray / Emote |

### Building

| Key / Input     | Action            |
| --------------- | ----------------- |
| `Z` `X` `C` `V` | Building pieces   |
| `R`             | Rotate build item |
| `G`             | Edit mode         |
| `Left Click`    | Build / place     |

## Controller Support

The game supports **keyboard + mouse** as well as **controller input**.
