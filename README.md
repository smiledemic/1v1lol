## ExternalBuild

An external build that is self contained. Download or fork it to start.

The current repository also supports GitHub Pages. Just click the URL on the right side of the screen to check it out before forking or downloading if you'd like.

Don't expect much from `LocalBuild`. It is just the same thing but requires a larger amount of storage space because it doesn't rely as heavily on external URLs.

For web browser usage, **ExternalBuild is exactly what you need.**

### Builds

**ExternalBuild**

* Self contained
* Smaller storage requirements
* Designed for web browser usage
* Uses external URLs where needed

**LocalBuild**

* Coming soon
* Requires more storage
* Relies less on external URLs
* More locally contained

## Controls

### Movement

| Key             | Action   |
| --------------- | -------- |
| `W` `A` `S` `D` | Movement |
| `Space`         | Jump     |
| `Left Shift`    | Crouch   |

### Interaction & Weapons

| Key / Input       | Action        |
| ----------------- | ------------- |
| `E`               | Pick up       |
| `F`               | Pickaxe       |
| `1` - `5`         | Weapon slots  |
| `Left Click`      | Shoot         |
| `Hold Left Click` | Zoom          |
| `B`               | Spray / Emote |

### Building

| Key / Input     | Action            |
| --------------- | ----------------- |
| `Z` `X` `C` `V` | Building pieces   |
| `R`             | Rotate build item |
| `G`             | Edit mode         |
| `Left Click`    | Build / place     |
